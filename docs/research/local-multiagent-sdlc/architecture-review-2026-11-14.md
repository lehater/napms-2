## Проверенные факты

- На `main` уже действует Codex CLI с проектными субагентами, OpenSpec и локальным `check-fast.py`. Преимущества нового рантайма пока не измерены.
- OpenCode V2 документирует `agents`, `permissions`, per-agent models, sessions и `opencode run --continue/--session/--format json`; возможность **выполнять целый внешний DAG с crash-safe exactly-once** из этого не следует.
- По текущей документации OpenCode, `shell` запускается с правами ОС. Доступ вне проекта по умолчанию может быть разрешён; исключения и `edit: deny` не дают полноценного sandbox.
- `main` продвинулся с `688cbce` (base PR #68) до `e957bd4` (Resource/Endpoint PR #67). Перед integration/rebase обновить base и перепроверить документы о состоянии продукта.

Официальные источники: [OpenCode V2 Agents](https://opencode.ai/docs/agents), [Permissions](https://opencode.ai/docs/permissions), [CLI](https://opencode.ai/docs/cli/commands), [SDK](https://opencode.ai/docs/build/sdk), [Providers](https://opencode.ai/docs/providers).

## Архитектурный вердикт

- **ADR-001 — ACCEPTABLE WITH CONDITIONS:** OpenCode V2 как *кандидат на пилот*; Codex CLI — подтверждённый baseline и fallback. Не объявлять платформу выбранной до проверенного локального окружения, доступных entitlement и одного ограниченного сравнения.
- **ADR-002 — ACCEPTABLE WITH CONDITIONS:** сначала режим A для непрерывного исполнения в активной сессии. Если владелец требует unattended restart и проверка A не обеспечивает этого, внедрять режим B — минимальный контроллер с записанным состоянием, reconciled side effects и owner gates.
- **Authorization:** принятие обоих ADR, публикация веток и merge остаются за владельцем; обновление архитектуры в Draft PR такого разрешения не создаёт.

## Следующее исполнимое действие

Не запускать абстрактную «платформу автокодинга». В отдельном disposable worktree проверить: `opencode --version` и V2 schema, реальный список моделей/провайдеров без записи токенов, загрузку OpenSpec Skills и `AGENTS.md`, модель роли, read-only изоляцию (включая shell), один завершённый session-run с OpenSpec и review. Затем сравнить с уже работающим Codex на таком же ограниченном задании. Реализацию Controller планировать **только при подтверждённом требовании B**.
