## Цель

Разработать *полную* целевую архитектуру локальной разработки с разделёнными ролями, контекстами и переключаемыми моделями/провайдерами. Внешний ChatGPT не должен быть обязательным координатором каждого изменения. GitHub `main` остаётся источником принятых решений; владелец утверждает продуктовые и архитектурные развилки, приёмку и merge.

## Архитектурная база для этапа A (решение принято, эксплуатационная приёмка впереди)

- **Выбранный путь внедрения:** OpenCode V2 по подтверждённому локальному пилоту #69. Результат ограничен workflow-mode A и проверенными правами; окончательное решение о замене рабочего Codex и качестве разных моделей принимается после bounded реальной задачи.
- **Базовая система и резерв:** установленный Codex CLI с поддерживаемыми проектными субагентами. Он уже подтверждён в PR #60; миграция не должна разрушить рабочий путь.
- **Оркестрация:** режим A1 — локальный Orchestrator в одной совместимой сессии; режим A2 — логический run через раздельные Sol-host/Worker-sandbox с объективным переходом между стадиями (пока вручную). Режим B — **условный** durable Controller с checkpoint/restart при подтверждённой необходимости. Explorer, Architect, Planner, Worker, Reviewer — LLM-специалисты; Validator — без LLM. Контракт описан в ADR-002.
- **Режимы моделей:** сильный / стандартный / экономичный / локальный; назначение по сложности, критичности и доступности. Без выдумывания API для чтения лимитов.
- **Принцип:** сначала описать *весь* целевой дизайн; затем внедрять через проверяемые изменения с возможностью отката.

**Одна непрерывная работа** означает последовательное выполнение разрешённых задач, а не бесконтрольное отсутствие остановок: при owner gate, P0 и исчерпании бюджета требуется остановка. Безопасный unattended restart не обещается режимом A и требует режима B.

Это архитектурный выбор на основании документации **и принятого пилота #69**: OpenCode v2.2.0, Ollama Qwen, OpenSpec, role permissions, bwrap и GitHub Verify FULL проверены в ограниченном сценарии. ChatGPT-модель прошла отдельный интерактивный запрос, но не использовалась в самом маршруте; качество постоянных ролей и обработка отказов ещё не подтверждены.
