## Проверка и приёмка

Команды из корня репозитория:

```sh
npm run build --prefix web
npm run test:semantic --prefix web
openspec validate --all --strict
NAPMS_PYTHON="$PWD/.venv/bin/python" npm run test:e2e --prefix web
```

Для Chromium в локальной среде может потребоваться установленный набор системных библиотек. E2E создают собственную SQLite БД; реальные сценарии проверяют сохранение и перезапуск backend, переключение actor, границы авторизации, фокус и черновики. Новые проверки мобильного меню охватывают 320/390 px. Существующая CI также проверяет backend.

Smoke: открыть Resources на 320/390 px, проверить видимость заголовка и открытие/закрытие меню клавиатурой. В local-demo выбрать Requester, ввести название процесса из пробелов и исправить ошибку; заполнить черновик, перейти в Resources и вернуться. Проверить очистку после смены actor. Создать заявку явным demo-примером, переключиться на Decider, выбрать ALLOWED, отменить и проверить возврат фокуса; подтвердить повторно и проверить сохранённый результат после обновления.

OpenSpec-контракты и задачи #52 в этой ветке не изменены; реализация композиции из Need не заявляется завершённой. Приёмка владельцем должна быть записана в PR перед squash merge.
