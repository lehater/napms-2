## GitHub research

- [#153 — Findings taxonomy and execution analysis](https://github.com/lehater/napms-2/issues/153) examines how to turn execution evidence into Findings while separating observed facts from hypotheses, routine probes, and actual problems. It calls for evidence-first manual review with deterministic facts. It rules out an analyzer, mandatory taxonomy or judge gate, paid or synthetic evaluations, and Harness changes. The merged documentation artifact is [`docs/engineering/sdlc-150-issue-153.md`](https://github.com/lehater/napms-2/blob/main/docs/engineering/sdlc-150-issue-153.md), delivered by [merged PR #160](https://github.com/lehater/napms-2/pull/160). Parent: #150; no native blockers listed.

- [#155 — Measuring effects of accepted improvements](https://github.com/lehater/napms-2/issues/155) defines defect-linked baseline and follow-up evidence, with outcomes such as confirmed, mitigated, unknown, or regression. It rejects arbitrary run counts, mandatory A/B tests, unsupported causal claims, and new telemetry or gates. The merged artifact is [`docs/engineering/sdlc-150-issue-155.md`](https://github.com/lehater/napms-2/blob/main/docs/engineering/sdlc-150-issue-155.md), delivered by [merged PR #162](https://github.com/lehater/napms-2/pull/162). Parent: #150; no native blockers listed. Operational effect remained unknown because comparable post-change observations and verified Langfuse access were unavailable.

- [#156 — Minimal analytics pilot plan](https://github.com/lehater/napms-2/issues/156) prepares an end-to-end pilot plan using the upstream access, Findings, problem-tracking, and effect-evaluation contracts. The plan covers inputs, outputs, roles, privacy and quality controls, costs, and stop conditions. It authorizes no runtime, schedule, dashboard, service, or automatic writes. The merged artifact is [`docs/engineering/sdlc-150-issue-156.md`](https://github.com/lehater/napms-2/blob/main/docs/engineering/sdlc-150-issue-156.md), delivered by [merged PR #164](https://github.com/lehater/napms-2/pull/164). Parent: #150; native blockers: #151–#155. The kickoff comment says all five were closed/Done, with PRs #158–#162 merged before #156 began, so #156 consumes all five upstream outcomes.

**Unknown:** The issue and PR records establish the documentation outputs and their stated limitations; they do not establish that a live analytics pilot ran or that operational effects were measured.
