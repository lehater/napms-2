# Анализ трейсов для исследования ролевой модели Harness

**Дата анализа:** 2026-11-22 UTC. Сырые тексты prompt и результатов инструментов в файлы не включены.

## 1. Источники и ограничения

- Langfuse Observations API v2 через установленный `langfuse-cli`; проект `Codex Observability`. Первичная инвентаризация: 7 160 observations с 2026-09-01. Подробная выборка ограничена четырьмя `sessionId` трёх выбранных Run ID и затем локально отфильтрована по точным `issueId` + `runId` из metadata.
- Метаданные Issues и итог `closed/completed` сверены в GitHub. Issue status подтверждает завершение; отдельное терминальное состояние trace осталось **Unknown**.
- `.ai/langfuse-read-access.md` в checkout отсутствует. Выполнены только успешные GET; фактический класс прав ключа независимо не подтверждался, операции записи в Langfuse не выполнялись.
- Usage прочитан из `usageDetails`. По агрегатам всех трёх выборок `total = input + input_cached_tokens + output + output_reasoning_tokens`; поля cache и reasoning сохранены отдельно. Максимум prompt оценён как `input + input_cached_tokens`, не как вклад конкретного инструмента. Langfuse описывает usage как отдельные типы потребления ([официальная документация](https://langfuse.com/docs/observability/features/token-and-cost-tracking), [Observations API](https://langfuse.com/docs/api-and-data-platform/features/observations-api)).
- Длительность — wall-clock от первой записи до последней, включая паузы и промежутки между сессиями; это не активное время. Размер результата — UTF-8 байты поля `output` верхнеуровневого TOOL observation. Если один `exec` объединяет вложенные вызовы, байты относятся к объединённому результату.
- Категоризация — детерминированная по имени инструмента и распознанному вложенному методу/команде. Счётчик `calls` ниже — число Langfuse TOOL observations; `nested` — распознанные вызовы внутри `exec`. Смешанные или непрозрачные wrappers отнесены к `прочее`. Повтор — точное совпадение входа верхнеуровневого observation; nested repeats отдельно не восстанавливались. Ошибкой считается только observation с уровнем `ERROR`; скрытые ошибки вложенной команды могли не поднять уровень wrapper.
- Проверены пути локальных журналов выбранных сессий: полные Codex `.jsonl` отсутствуют, доступны только небольшие `.jsonl.langfuse` sidecar-файлы. Они не дают содержимого событий compaction.

## 4. Динамика входных токенов

Последовательности находятся в `codex-role-model-trace-analysis-2026-11-22-model-calls.csv`; каждая строка содержит prompt estimate, preceding operations и объём их результатов для той же сессии. Операции связывались со следующим model call по времени завершения; это не утверждает точную причинную долю операции в prompt.

- #153: 93 последовательных вызова, оценка prompt 21 284–216 609; спадов между соседними вызовами не было.
- #126: 235 вызовов, 18 946–244 436; 2 резких спада: 244 436 → 21 609 (вызов 97) и 243 985 → 20 188 (вызов 222).
- #168: 339 вызовов в двух сессиях; 22 075–243 724 и 19 008–244 107. Три резких спада: 243 724 → 22 075, 240 932 → 21 605 и 244 107 → 23 792.
- Всего наблюдалось пять больших сокращений порядка 219–224 тыс. prompt tokens. В проверенных именах и event metadata TOOL observations явный compaction marker не найден; доступные sidecar-файлы не содержат событий compaction. Сокращения могут соответствовать compaction/reset, но это **не подтверждено**. Изменение размера prompt не приписывается отдельным предшествующим операциям.

## 6. Использование сабагентов

В трёх выбранных Run ID не обнаружено `spawn_agent`, `followup_task` или subagent observations; фактическое делегирование сабагентам не подтверждено. В #168 есть обращения Codex TUI к чтению/ожиданию/отправке сообщений в threads; они классифицированы как `прочее`, не как сабагенты. Эти три попытки не позволяют оценить эффект или стоимость делегирования.

## 7. Неизвестные и недоступные данные

- Terminal success/failure внутри Langfuse: Unknown; outcome взят из состояния GitHub Issue.
- Родительский Session ID или agent ID у model observations: Unknown; Langfuse предоставляет Session ID текущего observation.
- Reasoning effort доступен в `modelParameters` у выбранных поколений: `high` для #153, `xhigh` для #126 и #168.
- Полные локальные журналы Codex и явные compaction-события недоступны.
- Размеры вложенных ответов отдельно от результата `exec` wrapper и повторы вложенных вызовов: Unknown; замерены агрегированный wrapper output и точные повторы верхнего уровня.
- Read-only класс Langfuse credential: Unknown; использованы только GET запросы.
