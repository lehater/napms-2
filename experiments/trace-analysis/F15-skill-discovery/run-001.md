# F15 — preliminary skill discovery from recorded execution evidence

Status: PARTIAL — manual, report-based workflow induction; no independent raw trajectory extraction or held-out skill evaluation.

## Source review and adaptation

- [Agent Workflow Memory, ICML 2025](https://proceedings.mlr.press/v267/wang25bx.html), [method §2.3 and results §3.1](https://arxiv.org/html/2409.07429): identify common subtasks in successful experience, parameterize instance-specific values. WebArena task success 23.5% → 35.5% relative to BrowserGym; web-navigation setting.
- [Trace2Skill, EMNLP 2026](https://aclanthology.org/2026.emnlp-main.758/), [v3 §§2–4](https://arxiv.org/html/2603.25158v3): analyze success and failure independently, consolidate lessons; create or deepen skills. Evaluated on spreadsheet, math, visual QA, with transfer across models. These are not NAPMS effect estimates.
- [EvoSkill](https://arxiv.org/html/2603.02766v1): failure-based skill proposal and held-out selection, OfficeQA 60.6→67.9%, SealQA 26.6→38.7%; preprint. No automatic evolution in this pilot.
- [SkillDisCo, Findings EMNLP 2026](https://aclanthology.org/2026.findings-emnlp.2260/): executable shared procedural subgraphs from successful traces. Abstract verified; full HTML not retrieved. Not selected because control-flow reconstruction is currently costly and semantic coverage insufficient.

Manual adaptation: select documented episodes with explicit outcome, extract goal and recurring ordered subtasks, parameterize variable inputs, retain observed failures and stop rules, compare existing instruction/skills before proposing a change. Report-derived recurrence is not a validated common trajectory graph. No raw trace reads, no automatic skill generation.
