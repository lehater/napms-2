# F04 — run-001: guarded conformance checks on GitHub integration events

Status: PASS for a bounded retrospective manual check; not full AgentRx replication or measured diagnosis accuracy.

Method adapted from [AgentRx, EMNLP 2026](https://aclanthology.org/2026.findings-emnlp.598/): evaluate applicable constraints against execution evidence and preserve an auditable violation log. Coordinator used GitHub read-only API, not Langfuse or local CLI. Two deliberately selected merged PRs, #157 and #172. Unit of checking: integration event, not every agent step. No representative rate or causal attribution.

## Guarded rules

Both PR base versions of AGENTS.md contain the same integration requirement: record owner acceptance in the PR before squash merge; recheck CI on the final head after substantive fixes. For a merged PR, C1 checks successful Verify and six successful checks on its final head before merge. C2 checks explicit acceptance of the result recorded on the PR before merge (approval of requirements or merge itself is not the same record). For PR #157 only, C3 checks evidence of the reported OpenSpec task 2.4, owner visual acceptance and independent review prior to integration. C3 is not applicable to the docs-only #172. PASS = positive supporting record; MISSING_EVIDENCE = prerequisite not demonstrated by inspected artifacts, not proof the underlying activity did not occur. Do not treat missing recorded acceptance as lack of actual owner consent.
