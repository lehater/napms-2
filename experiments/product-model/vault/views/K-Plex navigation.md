# K-Plex navigation

Откройте NAPMS system mission в K-Plex. Для функциональной структуры центрируйте Govern network access; для предметных фактов — AccessSubject или PolicyRule.

K-Plex показывает отношения из YAML/Wikilinks. Не создавайте связи перетаскиванием ради расположения: семантические отношения правятся в канонической заметке и сверяются с metamodel.md. Plugin k-plex устанавливается отдельно.
