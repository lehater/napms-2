# Обзорные проекции

- [[Product Capability Map.base]] — 38 возможностей по сохранённой области; scope и implementation evidence раздельны.
- [[Operational Model.canvas]] — проблема, миссии, роли, процесс, деятельность и сценарии.
- [[Functional Breakdown.canvas]] и [[Functional Breakdown.base]] — декомпозиция системных функций, включая детализацию C05–C07 и C09–C10.
- [[Functional Chains.canvas]] — Submit/Decide/Export и композиция J01 до ConnectivityNeed: context involvements, exchanges, exchange items и локальный порядок.
- [[Logical Architecture.canvas]] — гипотетические Logical Components и назначенные logical functions, включая Business justification.
- [[Domain Model.canvas]] и [[Domain Model.base]] — доменные сущности, состояния и ограничения.
- [[Cross-level Traceability.canvas]] — operational → system → logical → component/capability trace.
- [[K-Plex navigation]] — динамическое исследование от корневых узлов.

Проекции не вводят и не меняют YAML-отношения.
